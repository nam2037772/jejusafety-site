> 이 문서는 "이 사이트가 누구에게, 무엇을, 어떤 말로 말하는가"를 고정합니다.
> 페이지 문구·서비스 이름·사례 제목을 쓸 때 이 문서를 먼저 봅니다.
> **최종 확정된 사업 범위** 기준입니다 (2026-08-27 확정).

> 대표·보조 메시지는 UX·SEO에 맞게 다듬을 수 있으나 **의미를 바꾸지 않습니다.**

### 브랜드 / 법인 표기 규칙

- 화면에 보이는 이름은 **제주안전시설** 하나입니다. (헤더·푸터·og:site_name·JSON-LD `name`)
- **(주)아인산업안전**은 계약·사업자정보·JSON-LD `legalName`·"운영회사" 자리에만 씁니다.
- 두 이름을 같은 자리에서 섞지 않습니다. 섞이면 검색엔진도 사람도 사이트 이름을 특정하지 못합니다.
- 신뢰 한 줄(trustLine): `운영 (주)아인산업안전 · 제주 전 지역 현장 대응`

## 2. 핵심 사업 — 두 축 (동등)

```
        ┌──────────────────────────────┐   ┌──────────────────────────────┐
        │  A. 안전시설 설치·교체·보수  │   │  B. 안전시설·안전자재 납품   │
        │     (현장 시공)              │   │     (조달·공급)              │
        └──────────────────────────────┘   └──────────────────────────────┘
                       ↘                        ↙
                    제주도 내 공공·교육시설 중심
```

**두 축을 동등하게 다룹니다.** 어느 한쪽을 부수적인 것으로 취급하지 않습니다.

- A만 강조하면 → 자재만 필요한 발주처가 이탈합니다
- B만 강조하면 → **전국형 안전용품몰**처럼 보여 지역 시공 브랜드의 해자가 사라집니다

## 3. 포지셔닝 — 무엇이 아닌가 (먼저 확정)

| 아니다 | 이유 |
| --- | --- |
| ❌ 전국형 안전용품 쇼핑몰 | 해자가 **제주 지역성**입니다. 전국 경쟁으로 나가면 가격 경쟁뿐입니다 |
| ❌ 일반 건설회사 | 대형 관급공사가 아니라 **소규모 설치·교체·보수** 구간이 강점 |
| ❌ 건설현장 가설 안전시설 업체 | 주 고객이 건설사가 아니라 **공공 발주처/관리주체** |
| ❌ 제조사 / 자재 브랜드 | 자재는 **선정·조달·납품**하는 쪽. 현장 판단이 상품 |

### 무엇인가

> **제주도 안에서, "금액은 작지만 미루면 위험해지는 시설"을 시공으로든 납품으로든 해결하는 팀.**

공공·교육기관 담당자가 겪는 전형적 상황:

- 파손된 시설 1~10개. 대형 업체는 견적조차 잘 안 나옴
- 육지 업체는 제주 출장비·배송비 때문에 단가가 안 맞음
- 직영 인력이 설치할 수 있으니 **자재만 납품**받고 싶은 경우도 많음
- 담당자는 현장 사진 한 장 들고 "이거 얼마예요?"를 물어볼 곳이 필요함

**제주안전시설은 정확히 이 자리를 차지합니다.**

## 4. 핵심 고객

### 1순위 — 공공·교육 (사이트 포지셔닝의 중심)

관공서 · 공공기관 · 준공공기관 · 학교 · 교육기관 · 공기업 · 공공시설 관리주체

### 2순위 — 제주도 내 민간 시설 (제한하지 않음, 문의 받음)

공동주택 · 병원 · 호텔 · 리조트 · 어린이집 · 사업장 · 기타 민간 시설

> **사이트의 얼굴은 공공·교육시설로 유지합니다.** 민간은 "제한하지 않는다"는 정도로 열어 둡니다.
> 문의 페이지와 서비스 페이지 하단에 "공동주택·병원·호텔·어린이집 등 제주도 내 시설도 문의 가능합니다" 한 줄로 처리하고,
> 히어로·주요 서비스 카드에는 올리지 않습니다.

### 담당자 관점

| 고객군 | 전형적 담당자 | 발주 특성 |
| --- | --- | --- |
| 관공서 (도청·시청·읍면동) | 시설 담당 주무관 | 소액수의, 연중 상시, 예산 소진기 집중 |
| 학교 / 교육기관 | 행정실장, 시설 주무관 | 방학기간 집중, 어린이 안전 명분 강함 |
| 공공기관 · 공기업 · 준공공기관 | 시설관리 담당 | 안전점검 지적사항 후속조치 |
| 공공시설 관리주체 (주차장·공원·체육시설) | 관리사무소 / 위탁 운영사 | 사고 발생 후 즉시 대응, 노후 교체 주기 |
| 공동주택 | 관리소장 | 입주민 민원 대응 |
| 병원·호텔·리조트·어린이집·사업장 | 시설/안전 담당 | 안전점검 대응, 이용객 안전 |

**공통점:** 담당자는 시설 전문가가 아니고, "무엇을 어떤 규격으로 얼마에"를 스스로 정하기 어렵습니다.
→ 사이트의 역할은 **담당자가 결재 올릴 수 있는 근거(사례·규격·절차)를 대신 만들어 주는 것**입니다.

## 5. 영업 지역 — 제주도 (매우 중요)

**제주시 · 서귀포시 · 제주도 내 읍·면 지역**

### 금지 표현

- ❌ 전국 시공 / 전국 출장 / 전국 설치 / 전국 배송 / 전국 어디든
- ❌ 육지 시공을 주요 서비스처럼 서술하는 문장
- ❌ 전국 단위 키워드를 노린 페이지 (`안전시설 설치업체`, `차선규제봉 판매` 등 지역 없는 상위어)

### 대신 쓰는 표현

- ✅ 제주 전 지역 현장 대응 / 제주시·서귀포시 및 읍·면 지역
- ✅ 지역명을 사례 제목과 요약표에 실제 값으로

> SEO도 같습니다. **모든 주 키워드에 `제주`가 들어갑니다.** 지역 없는 키워드는 노리지 않습니다.

## 6. 고객의 실제 언어 (검색어 = 문제 서술)

고객은 "안전시설물 시공업체"라고 검색하지 않습니다. **시설 이름 + 상태**로 검색합니다.

| 고객이 겪는 상황 | 실제로 치는 말 |
| --- | --- |
| 주차장 출구에서 사고 날 뻔함 | 제주 출차주의등 설치 |
| 규제봉이 차에 치여 부러짐 | 제주 차선규제봉 교체 |
| 중앙선 침범 잦음 | 제주 시선유도봉 설치 |
| 그레이팅이 덜컹거림 / 발 빠짐 | 제주 배수로 그레이팅 교체 |
| 학교 출입구 턱에 걸림 | 학교 경사로 진입판 |
| 해풍에 대문이 녹슴 | 제주 스텐 자바라 대문 |
| 자재만 사서 직영으로 설치하려 함 | **제주 안전시설 자재 납품** / 제주 시선유도봉 구매 |

→ **서비스 페이지 제목은 시설명으로 씁니다.** "종합 안전시설 시공" 같은 상위어로 쓰지 않습니다.

## 7. 강점 = 해자 (근거 있는 것만)

> **제주 지역성 + 실제 현장 경험 + 공공·교육시설 경험 + 자재 조달 + 소규모 설치·교체·보수 대응**

| 강점 | 사이트에서 증명하는 방법 |
| --- | --- |
| 제주 지역성 | 제주시/서귀포시/읍면 사례를 지역명과 함께 노출. 전국 표현 없음 |
| 실제 현장 경험 | **실제 시공사례가 서비스 구성의 근거.** 안 해본 일을 서비스로 만들지 않음 |
| 공공·교육시설 경험 | 발주처 유형 배지 (관공서·학교·공공기관) |
| 자재 조달 | 납품 문의 경로 + 쇼핑몰(ainsafety.com) 두 갈래 |
| 소규모 대응 | "1개소부터 시공·납품" 명시 |
| 법인 신뢰 | 등록 업종에 **안전용품 · 시설물 유지관리 공사업** 보유 |

### 쓰지 않는 표현

- 제주 1위 / 최고 / No.1 / 최저가 (근거 없음, 공공 발주처 대상 감점 요소)
- "토탈 솔루션", "원스톱 시스템" 같은 공허한 템플릿 문구
- 하지 않는 일(대형 토목, 신호기 제작, 도로 포장 전면 재시공)

## 8. 서비스 구성 원칙 — 사례가 먼저다

```
우리가 실제로 해본 일  →  사례  →  서비스  →  새로운 문의
```

- **상상한 서비스로 사이트를 키우지 않습니다.** 서비스 페이지의 "수행 작업"은 실제 사례가 뒷받침하는 항목을 앞에 둡니다
- 실적이 있는 시설·작업을 우선 노출합니다 (차선규제봉·시선유도봉·출차주의등·그레이팅·경사로 진입판·경계석·반사시설·스텐 자바라 대문)
- 실적이 아직 없는 항목은 "대응 가능" 수준으로만 적고, 사례가 생기면 승격합니다

## 9. 메시지 계층

```
1층 (히어로)   제주 공공·교육시설의 안전 문제를 현장에서 해결합니다.
2층 (부제)     관공서·공공기관·학교의 안전시설 설치·교체·보수부터 안전자재 납품까지
3층 (증거)     제주시·서귀포시 실제 시공사례
4층 (행동)     현장 견적 문의  /  자재 납품 문의
```

### 톤

- 담당자 대 담당자. 광고 문장이 아니라 **업무 문장**
- 문장은 짧게. 수치·규격·지역명을 넣어 구체적으로
- 감탄사·과장 없음. "안전한 제주를 만들어갑니다" 류의 슬로건형 문장 금지

## 10. 전환 흐름 — A·B 동등

### A. 설치가 필요한 고객

```
시설 문제  →  서비스 확인  →  실제 제주 시공사례  →  현장 확인 / 견적 문의  →  설치·교체·보수
```

예: `제주 시선유도봉 설치` 검색 → `/service/road-traffic.html` → 설치 방식·규격 → 제주 사례 → **현장 견적 문의**

### B. 자재가 필요한 고객

```
필요한 시설·자재 확인  →  제품 안내  →  납품 문의  또는  쇼핑몰 구매
```

예: `제주 차선규제봉 납품` 검색 → `/products.html#traffic` → 규격·선택 기준 → **납품 문의(수량·현장)** / **쇼핑몰에서 구매(소량·직접)**

> 제품 페이지의 CTA는 **두 개를 나란히** 둡니다.
> `납품 문의`(관수·대량·세금계산서) 와 `쇼핑몰에서 구매`(소량·직접 설치).
> 쇼핑몰 링크만 두면 관수 납품 수요를 놓칩니다.

## 13. 성공 판단 기준 (MVP)

1. "제주 + 시설명 + 설치/교체/납품" 검색에서 해당 페이지가 잡힌다
2. 담당자가 사례 1건만 보고도 "이 업체면 되겠다"고 판단할 수 있다
3. 모바일에서 3탭 안에 전화 연결이 된다
4. **자재만 필요한 고객이 이탈하지 않고 납품 문의로 이어진다**
5. 새 사례 1건 추가가 **Raw 자료 투입 → AI 구조화 → 검증 → 빌드** 로 끝난다
